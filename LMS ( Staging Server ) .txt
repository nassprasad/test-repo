Looking at your LMS environment

Your application stack appears to be:

Nginx → Reverse proxy handling HTTPS.
Node.js → Main application.
MongoDB → Stores licenses, users, and other persistent application data.
Valkey → Stores cached data, user sessions, and possibly background job information to improve performance.

--------------------------------------------------------------------------------------------

dockerd is the Docker management service. ( dockerd communicates with containerd )
containerd 	- manages the running containers.
node is your application process inside the app container.
mongod is the MongoDB process inside the MongoDB container.


# Check Docker daemon
sudo systemctl status docker

# Check container runtime
sudo systemctl status containerd

# List running containers
sudo docker ps
